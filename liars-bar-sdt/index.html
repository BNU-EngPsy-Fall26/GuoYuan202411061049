每一轮，对面的酒客会把牌推到你面前，报出一个点数。你要判断的只有一件事： 他在说谎，还是在说实话。 「他在说谎」是信号，「他说实话」是噪音；你按下按钮的那一刻，就是一次信号检测。

四种结果，都写在酒馆的账上

客观世界只有两种状态：他在说谎（信号 S），或者他说实话（噪音 N）。 你只有两种反应：喊「你骗人」（报有信号），或者信他（报无信号）。 两者交叉，就是信号检测论的四格表。

你喊「你骗人」
你说「相信他」
他在说谎（S）
H 命中抓到了当场揭穿，对手喝罚酒，你 +1
M 漏报被他骗了谎言从你眼皮底下过去，你 −1
他说实话（N）
FA 虚报冤枉好人牌翻开是真的，你 −1
CR 正确拒绝稳稳跟牌什么都没发生，你 +1

结算时会算这几个量

命中率 p(H) = H / (H + M)　　虚报率 p(FA) = FA / (FA + CR)

辨别力 d′ = z(p(H)) − z(p(FA))　　z 是标准正态的逆累积分布 Φ⁻¹

判断门槛 c = −0.5 · [ z(p(H)) + z(p(FA)) ]　　c > 0 保守，c < 0 激进

似然比 β = exp(c · d′)　　准确率 = (H + CR) / 总试次

d′ 衡量的是你能不能分辨，c 衡量的是你有多容易起疑。 这两个数必须分开看：一个从不说「你骗人」的人和一个从不放过一个可疑眼神的人， 准确率可能一样，但 d′ 与 c 完全不同。

若某一格为 0（例如一局里一次都没虚报），p 会取到 0 或 1，z 值发散。 程序会自动改用 log-linear 规则（四格各加 0.5）修正，并在结算时明确标注 —— 不悄悄改你的数据。依据是 Hautus (1995) 的 5 万次蒙特卡洛比较： log-linear 比常用的 1/(2N) 规则偏差更小。

最优门槛那一栏来自贝叶斯决策：在「判对 +1 / 判错 −1」的对称收益下， β_opt = P(N)/P(S)，于是 c_opt = ln[P(N)/P(S)] / d′。 谎话率一高，理性策略就该变得更爱怀疑 —— 这个数会自动往负方向走。
